# Referencias

Material de consulta. No es de autoría del proyecto y no se entrega: está aquí para que
cada regla del validador se pueda rastrear hasta su fuente.

| Archivo | Para qué se usa en el proyecto |
|---|---|
| `TAREA FINAL AUTÓMATAS PD.pdf` | enunciado del profesor: alcance, entregables y rúbrica |
| `CIS_Benchmarks_Password_Policy_Guide_v21.12.pdf` | valores operativos de la política de contraseñas (longitud, historial, bloqueo) |
| `PCI-DSS-v4_0_1.pdf` | requisito 8.3, usado como contraste con NIST y CIS |

NIST SP 800-63B no está en el repositorio por ser de dominio público y voluminoso: se cita
por sección en `docs/plans/app-credenciales/plan.md` y en el documento del proyecto.
